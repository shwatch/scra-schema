# delay

## Status

Draft

## IRI

```text
https://scra-schema.org/vocab/delay
```

## Kind

NGSI-LD Property

## Domain

`PassingEvent`, `MonitoredVehicleJourney`

## Value

Duration, normally expressed in seconds with NGSI-LD `unitCode` `SEC`

## Definition

The deviation of an operational or predicted time from the applicable
scheduled or target time.

A positive value normally represents lateness and a negative value normally
represents an early event, subject to the applicable source mapping profile.

# eventType

## Status

Normative

## IRI

```text
https://scra-schema.org/vocab/eventType
```

## Kind

NGSI-LD Property

## Domain

`PassingEvent`

## Definition

Classifies the operational nature of a PassingEvent.

Initial values may include:

- `arrival`
- `departure`
- `passing`

A profile may define additional controlled values when their semantics are
documented.

## Status

## IRI


## Kind

Entity Type / Semantic Class

## Normative Declaration

`https://scra-schema.org/vocab/Organisation` is the canonical SCRA vocabulary IRI for the `Organisation` semantic
class.

Conforming implementations that represent the SCRA `Organisation` class as an
IRI SHALL use this IRI unless a specification profile explicitly defines an
equivalent external vocabulary term and declares the mapping.

The compact JSON-LD term `Organisation` SHALL expand to this IRI through the
SCRA Mobility Context.

## Semantic Definition

The semantic meaning, identity rules, role neutrality, relationships, and
constraints of this term are defined by the
[Organisation semantic model](../models/Organisation.md).

This vocabulary declaration assigns the stable SCRA IRI. It does not replace or
duplicate the semantic model.

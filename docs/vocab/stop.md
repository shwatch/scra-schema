# stop

## Status

Draft

## IRI

```text
https://scra-schema.org/vocab/stop
```

## Kind

NGSI-LD Relationship

## Domain

`PassingEvent`

## Range

`PublicTransportStop`

## Definition

Relates a PassingEvent to the PublicTransportStop at which the operational
arrival, departure, or passing event occurs.

Where the same journey visits the same stop more than once, sequence or
PointInJourneyPattern information is required to preserve occurrence identity.
